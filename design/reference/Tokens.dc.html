Build rules for Claude Code

  • Colors, radii and fonts come from design/tokens.css only.
  • Server components by default. Client JS: pass picker, checkout form, scanner.
  • Checkout, ticket, policies and scanner: no chrome text, 16px body, real contrast.
  • Every async button has idle, loading, error and success states.
  • Photos: next/image, WebP, fixed dimensions, lazy except the hero.
  • Check each screen at 390px, then 1280px, before moving on.

Bracketed text is content to fill in. Nothing here is a finished fact.
